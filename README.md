# 文件重命名复制工具

一个实用的文件管理工具，可以递归遍历文件夹，将文件按文件夹层级重命名并移动到根目录。

## 功能特点

- ✅ **自动获取当前目录** - 将程序放在哪个文件夹就在哪个文件夹使用
- ✅ **递归处理子文件夹** - 支持最高 10 层深度的子文件夹
- ✅ **按层级重命名** - 使用文件夹名称作为前缀重命名文件
- ✅ **移动文件** - 将文件移动到根目录（原文件会被删除）
- ✅ **智能缩略** - 超长文件名自动缩略（保留前后 6 字符 + 省略号）
- ✅ **日期保护** - 自动识别并保护日期格式（YYYY-MM-DD）不被缩略
- ✅ **非法字符清理** - 自动替换 Windows 文件名中的非法字符

## 使用示例

### 基本用法
```
原始结构:
  ./2024-05-21/post.json
  ./2024-05-21/xxxx/photo.png

处理后:
  ./2024-05-21 post.json
  ./2024-05-21 xxxx photo.png
```

### 多层级文件夹
```
原始结构:
  ./2024-05-21/1/2/3/document.pdf

处理后:
  ./2024-05-21 1 2 3 document.pdf
```

### 长文件名自动缩略
```
原始结构:
  ./2023-01-01 qwertyuiopasdfghjklzxcvbnm/file.txt

处理后:
  ./2023-01-01 qwerty...xcvbnm file.txt
```

## 使用方法

1. 将 `rename-all-file-for-here.exe` 复制到要处理的文件夹
2. 双击运行程序
3. 程序会自动处理当前文件夹下的所有一级子文件夹
4. 处理完成后按回车键退出

## 编译说明

### 环境要求
- Python 3.7+
- PyInstaller

### 编译步骤
```bash
# 安装依赖
pip install pyinstaller

# 编译为单个 exe 文件
pyinstaller --onefile rename-all-file-for-here.py

# 编译完成后，exe 文件位于 dist/rename-all-file-for-here.exe
```

## 注意事项

- ⚠️ **文件会被移动** - 原文件会被移动到根目录，不会保留在原位置
- ⚠️ **文件名冲突** - 如果目标文件名已存在，会跳过该文件
- ⚠️ **日期格式保护** - YYYY-MM-DD 格式的日期不会被缩略
- ⚠️ **非法字符替换** - `< > : " \ / | ? *` 会被替换为下划线

## 技术细节

### 文件名缩略规则
- 非日期部分超过 15 个字符时自动缩略
- 保留前后各 6 个字符，中间用 `...` 连接
- 日期格式（YYYY-MM-DD）始终保持不变

### 支持的字符
- 支持 Unicode 字符（中文、日文、韩文等）
- 自动清理 Windows 文件名非法字符
- 自动移除控制字符（ASCII 0-31）
